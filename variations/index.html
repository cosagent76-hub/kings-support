House rules

Kings Rule Variations

The standard help flow uses the family default rules. Variations can be fun, but agree on them before hand 1 starts so the table does not renegotiate mid-game.

Standard Rules Table FAQ Download One-Page Rules

Standard Family Default

DeckOne standard deck plus two jokers.
Players2 to 6 players.
First turnDealer gets 8 cards, does not draw, and discards to start the discard pile.
Aces in runsAces are low only. A-2-3 works. Q-K-A does not.
Going outNo final discard required. If your play uses your last card, the hand ends.
Wild replacementAllowed for eligible wilds. A run wild can be replaced or covered by the real card.

Good Variations to Try

Learning Game

Keep the help page open, pause for rules questions, and allow table talk for younger or brand-new players.

Short Game

Stop after hand 5, 7, or 10 and let the lowest score win. This is useful for weeknights or family games with younger players.

Final Discard Required

Some tables require a discard to go out. If you choose this, say it clearly before the first deal.

Aces High or Low

This allows Q-K-A as well as A-2-3. It makes runs easier, so use it only if everyone understands the change.

No Wild Replacement

For a simpler beginner game, leave wilds where they are once played. This removes the replace-or-cover decision.

Stalemate Rule

If nobody can make progress after repeated reshuffles, end the hand and score cards left in hand.

Be Careful Changing These

  • Deck count: adding a second deck changes set limits and duplicate-card questions.
  • Jokers: removing jokers makes wild play less frequent and changes scoring pressure.
  • Wild rules: make sure everyone knows whether wild replacement is allowed before the first wild hits the table.
  • Going out: final-discard rules affect strategy late in the hand.
